An invented passport spread for the Republic of Velmaris — a lighthouse island nation in the Adriatic. A Python + PIL program draws the data page (stylised portrait, personal data, machine-readable zone with correct ICAO check digits, seafarer endorsement) and the visa page (a Sardonia visa sticker with a harbour-master reporting condition, plus arrival/departure stamps from Daruvia, Aldorra, Sardonia and the Kosten Islands forming one coherent travel history, June–October 2026, all after the passport's issue date of 02 JUN 2026).

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```

Writes `/tmp/out/entry.png` (1024×1024 PNG, deterministic — two runs are byte-identical).
